# Debt ledger

Accepted debt is a choice with an owner and a condition that clears it. It is not a failed review.

`/record-debt` records technical debt you choose to keep. Untracked debt items to fix should be drafted as an intent via `/new-intent`.

Each entry is `docs/debt/TD-NNN-<slug>.md`, copied from [_template.md](_template.md). The agent writes Status `proposed`. Only a human sets `accepted`.
